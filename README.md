# JB3 Capital - Além do Metro Quadrado

Newsletter Além do Metro Quadrado (JB3 Capital e Kyrtos)

Arquivos públicos usados no envio da newsletter pelo RD Station.

A newsletter sai em um e-mail por semana, toda terça-feira, às 7h, com uma cidade por vez: Florianópolis, São José, Tubarão e Bento Gonçalves.

- `NNN/`: imagens dos e-mails de cada edição. Os e-mails apontam para um commit fixo, então a imagem de um e-mail já enviado não muda.
- `emails/NNN/edicao.html`: o e-mail pronto de cada edição, para copiar e colar no bloco HTML do RD.
- `emails/000/carta.html`: a carta de apresentação, enviada antes da primeira edição.
